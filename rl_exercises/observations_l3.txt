Level 3 Observations: Prioritized Replay and Double DQN

For Level 3, I compared four DQN configurations on CartPole-v1:

1. Base DQN
2. DQN + Prioritized Experience Replay
3. DQN + Double DQN
4. DQN + Prioritized Experience Replay + Double DQN

The Base DQN configuration achieved the weakest overall performance. It learned more slowly and reached lower rewards compared to the enhanced variants.

Adding Prioritized Experience Replay improved learning because the replay buffer sampled transitions with larger TD-errors more often. These transitions are usually more informative for the update, so the agent can focus more on experiences where the current Q-network prediction is still inaccurate.

Double DQN also improved performance. In standard DQN, the target uses a max operation over Q-values, which can lead to overestimation. Double DQN reduces this problem by using the online network to select the best next action and the target network to evaluate that action.

The combination of Prioritized Replay and Double DQN achieved the strongest overall performance in the ablation experiment. This can be seen both in the training curves and in the RLiable aggregate metrics.

The training curves show that all methods behave similarly during the early exploration phase. After enough transitions are collected, the improved variants begin to learn faster than the base DQN.

The confidence intervals become wider later in training, which shows that performance varies across random seeds. This confirms again that single-seed results can be misleading in reinforcement learning.

The RLiable metrics provide a more reliable comparison than only looking at one training curve. Mean, median, IQM, and optimality gap together give a better view of the robustness of each method. In particular, IQM is useful because it is less sensitive to outlier runs than the plain mean.
