We used a contextual MarsRover with three features:
action_success_prob, left_goal_reward, and right_goal_reward.
These affect transition dynamics and rewards. Contexts change after each reset and are split into train, validation, and test sets.

Results:

Without context:
train: 37.83, val: 40.27, test: 24.67
→ Learned one compromise policy: [0, 0, 1, 1, 1]
With context:
train: 46.00, val: 46.97, test: 16.10
→ Learned separate policies per context

With hidden context, the agent cannot adapt and learns an average policy.
With visible context, it adapts better to training contexts, improving train/validation performance.

However, performance drops on the test set because the tabular representation encodes context IDs, not their meaning. The agent memorizes policies per context instead of generalizing. When new contexts appear, this fails.

Conclusion:
Making context visible helps on known contexts but hurts generalization. To match the paper’s goal, the agent needs a method that learns from context features, not just context IDs
