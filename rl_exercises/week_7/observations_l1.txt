Level 1: Random Network Distillation

We implemented Random Network Distillation (RND) for DQN and PPO. The RND implementation uses a frozen random target network and a trainable predictor network. The intrinsic reward is computed as the mean squared prediction error between the predictor output and the target output. Therefore, states that are still hard to predict receive a higher novelty bonus, which follows the idea from the lecture that novel states are less predictable and can be used to guide exploration.

For the experiment, we compared the standard DQN agent with epsilon-greedy exploration against RND-DQN on CartPole-v1. We used the provided configuration files without changing the hyperparameters and ran both methods over five random seeds. The plot reports only the extrinsic episode return from the environment. This is important because RND adds an intrinsic reward during training, but the final performance should still be evaluated using the original task reward.

The normal comparison curve shows that DQN improves earlier and reaches a higher peak in some runs. RND-DQN learns more slowly at the beginning, but later becomes competitive with the baseline. The RLiable IQM curve confirms this interpretation: both methods end with very similar performance. The final RLiable statistics show an IQM of approximately 184.46 for DQN and 185.34 for RND-DQN. However, the mean return is higher for DQN, around 190.17 compared to 181.42 for RND-DQN. Since the confidence intervals overlap strongly, We would not interpret this as a clear advantage for either method.

This result makes sense for CartPole-v1. The environment has a dense reward signal, and epsilon-greedy exploration is already sufficient to collect useful experience. RND is more useful when discovering novel or rarely visited states is important, for example in sparse-reward or hard-exploration environments. In CartPole-v1, the additional intrinsic reward can even make learning less stable because the Q-network learns from a mixed reward signal consisting of the environment reward and the novelty bonus.

For DQN, RND is easy to integrate because the intrinsic reward can simply be added to the reward stored in the replay buffer. However, this also means that the Q-values are trained on a modified reward function, which can distract the agent if novelty is not actually useful for the task. For PPO, RND can also be used, but it requires more care because PPO is on-policy. In our implementation, we used separate extrinsic and intrinsic value heads and computed separate GAE streams before combining the advantages. This makes PPO-RND conceptually cleaner, but also more complex.

Overall, RND was implemented successfully and the training runs show that it works as a novelty-based exploration bonus. However, on CartPole-v1 it does not clearly outperform epsilon-greedy DQN. We would expect RND to show a clearer benefit on environments where state coverage and discovering novel states are more important.
